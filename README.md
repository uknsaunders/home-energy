# Home Energy

A one-page dashboard for an Octopus Energy smart-meter account. Each time it's opened it fetches the latest half-hourly gas and electricity readings from the Octopus API and shows daily costs, time-of-day use, likely car charging, overnight heating alerts, Direct Debit tracking and tariff comparisons.

Open it at https://uknsaunders.github.io/home-energy/ and enter the account number and API key in Settings. Both are stored only in that browser — nothing personal is kept in this repository.
