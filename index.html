Keep these settings safe

The settings stay on this phone until the browser's data is cleared. In DuckDuckGo the flame (Fire) button clears it, unless the site is fireproofed: open the page, tap ⋮ and choose Fireproof site. Adding the page to the home screen also helps.

As a backup, copy a setup code and keep it somewhere private, such as a password manager. Paste it back here to restore everything in one go. It contains the API key, so treat it like a password.
